# BARF 0.1.2

A lightweight, local-only Android reader for sources you choose. Android 8.0 or newer.

## Install

Download **BARF-0.1.2-preview.apk** (1.67 MiB). Android may ask you to allow installs from your browser or file manager. Install over your current copy to keep sources, topics, and saved items. The app name is now **BARF**; version code remains **3** and the optimized APK reports **0.1.2-preview**.

## Included

- Today, Topics, Saved, and Manage sources, with light/dark themes.
- RSS/Atom feeds, website feed discovery, and YouTube channel feeds.
- Original headlines and source previews; topic filters, save, and share.
- In-app article browser with page history, reload, Save, Share, and Open externally.
- Local storage, background refresh, and JSON backup/restore.
- 14-day retention for unsaved feed items; saved items remain until removed.

No server backend, account, analytics, AI summaries, or cloud backup.

## Validation and limits

Both APK builds and lint passed. The final automated suite passed 24 tests. APK signatures were verified against the existing development signing key. Physical-phone/emulator and real-site playback checks remain pending; this release is marked as a prerelease. Publisher ads, paywalls, and sign-in remain part of their pages. Some video, popup sign-in, and downloads may need Open externally. Full articles are not guaranteed available offline.

The debug APK, source archive, build report, and SHA-256 checksums are attached for reference. Use the preview APK for normal installation. Export a backup from Settings before uninstalling or moving devices.
